# Figma libraries to NICE Design System map

Maps components in NICE's Figma libraries to the coded design system, so that when the agent reads a Figma frame built from them it uses the right NDS component. Two libraries are covered, and both are read-only from this workspace:

- **NICE Design System kit**: the organisation's published library (under "Your organisation" in Figma).
- **Designers' toolkit**: built by the UX team.

**Status: not yet filled in.** Neither library has been read. To fill it in, open this workspace in Kiro with Figma connected and say:

> Compare the NICE Design System kit and our toolkit in Figma with the coded design system, and fill in the map. The kit is here: [link]. The toolkit is here: [link]

A design system maintainer should review the result before it is relied on.
